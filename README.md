# Japan trip · October 2026

Public itinerary with local private booking import. The site has no upload endpoint, analytics, or external JavaScript.

Use **匯入私人 JSON** to load a booking package shared directly by the trip organizer. Data and embedded images stay in this browser’s IndexedDB. **匯出 JSON** saves a copy; **移除私人資料** removes stored data. Browser data is specific to this site, device, and browser; clearing site storage removes it.

Do not commit private booking JSON, original confirmations, or precise residential lodging data to this repository. Private offline HTML/PDF and source materials are distributed separately.

Maps are GSI-derived illustrations accompanying the itinerary, with attribution and processing labels. Public residential-location maps use the general Tengachaya Station area. See MAP-SOURCES.md for terms. Destination photos preserve source/licence credits; the Tokyo track reference photo was supplied by the trip organizer and is not represented as openly licensed.
